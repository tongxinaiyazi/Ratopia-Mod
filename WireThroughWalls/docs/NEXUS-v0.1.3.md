# 电线可穿墙 v0.1.3 更新说明

## 修复

- 修复安装 v0.1.2 后部分建筑反复显示缺电警报，但实际电量与发电量充足的问题。
- 根因是同格端口协调器在每次验证时都会重跑全城耗电与发电建筑的供电判定；与“特殊鼠鼠”的“量子电网”等修改电网范围的功能同时使用时，可能把仍在供电的建筑重新标记为 `NoElec` 或 `NoBattery`。
- v0.1.3 将端口协调改为幂等检查：端口和线路未变化时不写入、不刷新；只有端口丢失、代表变化或线路确实需要合并时才修复对应坐标。
- 协调器不再调用全城耗电/发电建筑刷新，因此不会周期性重置其他 Mod 管理的供电状态。

## 保留功能

- 保留全建筑共格、门/铁路/电梯等特殊节点保护和同格多端口连接。
- 保留前景建筑优先、按住左或右 `Alt` 选择背景电线的拆除操作。
- 保留 v0.1.2 的同格建筑 `F` 查看详情修复。
- 不新增配置项或自定义存档字段。

请先完全退出 Ratopia 再替换 DLL。建议在备份存档中确认供电、F 键交互、分别拆除和保存重载后再覆盖正式存档。
