# 电线可穿墙验收清单

## 自动门禁

在项目根目录运行：

```powershell
Remove-Item Env:RATOPIA_DIR -ErrorAction SilentlyContinue
dotnet test .\WireThroughWalls.sln -c Release `
  --artifacts-path "$env:TEMP\WireThroughWalls-v013" `
  "/p:RatopiaDir=E:\steam\steamapps\common\Ratopia" `
  /p:InstallAfterBuild=false
```

预期结果：全部测试通过，0 个失败。测试会核对真实 `Assembly-CSharp.dll` 中的 Harmony 目标签名，并检查插件包不能携带游戏、Unity、BepInEx 或 Harmony 的运行库。

## 启动与日志

1. 启动游戏并进入一个专用测试存档。
2. 打开 `BepInEx/LogOutput.log`。
3. 确认插件被发现，所有 Harmony 补丁安装完成，且出现“电线背景与同格端口协调器已初始化”。
4. 确认没有“补丁安装失败”或“运行时协调失败”。

## 放置与施工

每项完成后都检查建筑仍存在、格子显示正常、施工任务可完成，并用供电设备确认电网仍连通。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| A1 | 先建墙，再把普通电线蓝图穿过墙 | 蓝图可放置，完工后墙和电线都存在 |
| A2 | 先建普通电线，再把墙建到同一格 | 墙可放置，完工后两者都存在 |
| A3 | 先建普通建筑，再把普通电线穿过它 | 两者共存，建筑功能不受影响 |
| A4 | 先建普通电线，再把普通建筑建到同一格 | 两者共存，电网仍连通 |
| A5 | 让普通电线与普通道路、壁纸和 `Wireroad` 分别共格 | 对象均保留，路径与供电正常 |
| A6 | 两种蓝图尚未完工时按两个顺序重叠放置 | 两个蓝图都保持启用并可施工 |
| A7 | 取消任意一方蓝图 | 只取消所选蓝图，另一方占位恢复正确 |
| A8 | 让普通电线分别穿过开关门、铁路与坡道 | 门可开关和通行，列车可行驶且坡度不变 |
| A9 | 让普通电线分别穿过普通电梯、电动电梯和升降轨道 | 电梯可调用、移动和通行，不发生卡位 |
| A10 | 让普通电线穿过抽水螺杆 | 螺杆节点和功能保持正常 |
| A11 | 在世界对象、地图机关、边界外、水体和原版无效区域尝试放线 | 仍被原版规则拒绝 |
| A12 | 站在电线与建筑的重叠格旁，重复按 `F` 并切换重叠目标 | 界面高亮哪个对象就打开哪个对象，不出现有提示但按键无响应 |

## 同格电力端口

分别让普通电线与下列对象的端口共格，并测试“先电线”和“后电线”两个顺序：

- 电池与变电站；
- 所有类型发电机；
- 特斯拉塔；
- 电动电梯；
- `Wireroad`。

每项都必须同时确认：

1. `Dic_PortTileMap` 的代表符合“前景电器 > Wireroad > 普通电线 > 同类低 ID”；
2. 两个所有者 ID 都在同一个 `ElecLine_Info.List_ID` 中；
3. 设备实际发电、蓄电或耗电正常，不能只看电线贴图；
4. 分别停工、复工和拆除任一对象后，幸存端口会被提升且继续供电。

## 拆除

1. 对同时包含电线和前景建筑的格子使用拆除工具。
2. 不按修饰键时确认选择的是前景建筑。
3. 按住左 `Alt` 或右 `Alt` 时确认选择的是普通电线。
4. 分别测试蓝图取消、施工中的电线取消和已建成电线拆除。

## 存档与会话

1. 保存“已建成电线 + 墙/建筑”的重叠状态，退出到标题并重新载入。
2. 保存“电线蓝图 + 墙/建筑”以及“普通蓝图 + 电线”的重叠状态，退出到标题并重新载入。
3. 确认读档后蓝图仍启用、成品仍共存、电网仍连通。
4. 新建或载入第二个存档，再返回第一个存档，确认没有把上一会话的格子状态带入当前会话。
5. 保存并连续重载两次，确认特殊节点、端口代表、线路成员和实际供电均保持正确。
6. 放置、取消和拆除后等待至少 2 秒，确认周期端口验证没有改变门、铁路、电梯等前景节点。

## 安装与文件门禁

必须先完全退出 Ratopia，再执行：

1. 备份已安装的 `v0.1.1` DLL；
2. 安装 `v0.1.3`；
3. 比较构建 DLL、发布包内 DLL 和安装 DLL 的 SHA-256；
4. 启动游戏，验证插件发现、补丁安装、首次补丁调用、会话初始化及行为日志。

游戏运行时不得替换 DLL。只有上述实机矩阵全部通过后才上传 Nexus Mods。

## 回退测试

在存档备份上执行：

1. 在 Mod 启用时拆除所有重叠电线并保存。
2. 退出游戏，移除 `WireThroughWalls.dll`。
3. 重新载入存档，确认原版游戏可正常继续。

不要用唯一存档测试卸载，也不要在游戏运行时替换 DLL。
