# 电线可穿墙 v0.1.1 更新说明

## 本次更新

- 将普通电线改为真正的背景对象，不再周期性重写前景格节点。
- 修复电线穿过普通/电动电梯后电梯失效、鼠鼠卡位的问题。
- 修复门、铁路坡度、升降轨道和抽水螺杆可能被错误改成普通建筑节点的问题。
- 修复拆除前景建筑后，同格普通电线可能无法重新连接的问题。
- 新增同格多端口协调：电池、变电站、发电机、特斯拉塔、电动电梯、`Wireroad` 和普通电线可保留各自端口并合并电网线路。
- 道路完工时不再自动拆除重叠普通电线。
- 拆除重叠格时默认选择前景建筑；按住左 `Alt` 或右 `Alt` 可选择背景普通电线。
- 旧存档中的重叠对象会原样保留；Mod 不会自动拆除、退款或保存。

## 兼容范围

普通电线可与所有建筑、建筑蓝图、墙、道路和电力设施共格。地图边界、水体、世界对象、地图机关及其他原版无效建造区域仍遵守原版限制。同一格不能重复放置两根普通电线。

## 升级提示

请先退出游戏并备份存档，再用 v0.1.1 DLL 替换旧版本。不要在 Ratopia 运行时替换 Mod 文件。

若要卸载，仍建议先在游戏内拆除所有与其他对象重叠的普通电线，保存并退出后再删除 DLL。
