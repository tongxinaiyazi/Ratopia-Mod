# 上帝视角管理实机验收

## 自动验证

在 Ratopia 已退出时执行：

```powershell
$env:RATOPIA_DIR = 'E:\steam\steamapps\common\Ratopia'
dotnet test .\GodViewManagement.sln -c Release /p:InstallAfterBuild=false
.\scripts\Package.ps1 -RatopiaDir $env:RATOPIA_DIR
```

合同测试会检查目标游戏程序集哈希、Harmony 目标方法签名、关键字段与枚举、插件元数据、补丁类和禁止的运行时引用。

## 游戏内功能

1. 暂时移走除 `GodViewManagement.dll` 以外的功能 Mod，启动游戏并进入存档；确认日志依次出现“上帝视角管理 v0.1.3 已加载”“独立运行时驱动已启动”和“检测到已载入的游戏会话”，HUD 只出现一次且仅有向左避让后的“上帝视角设置”入口。测试完成后恢复其他 Mod。
2. 模式关闭时测试移动、F 交互、建造、命令和所有常用 UI，确认行为与原版一致。
3. 按 `M` 切换模式；确认常驻 HUD 不再显示模式开关。打开设置，确认面板显示当前模式，并测试重新绑定、`Esc` 取消、修饰键拒绝、原版按键冲突提示和恢复默认。
4. 在设置中点击“隐藏 HUD”，确认整个 Mod HUD 消失且模式、相机和女王状态不变；按 `Shift + 当前切换键` 恢复，并确认该组合键不会同时切换模式。再次隐藏后切换存档，确认新会话恢复显示。
5. 开启模式时，若女王已有移动，确认其立即停止。随后在每次测试前后都记录女王坐标，并分别持续测试：
   - WASD；确认相机仍按现有行为移动、女王坐标不变。
   - 上、下、左、右四个方向键；确认女王坐标不变。
   - 手柄方向输入（若现场有手柄）；确认女王坐标不变。
   - 屏幕四边的边缘滚屏；确认相机仍可移动、女王坐标不变，且相机不能越出地图边界。
   关闭模式后，分别复验上述原版女王移动输入已恢复（手柄仅在现场有手柄时复验）。
6. 分别远程点击工坊、仓库、住宅和电力建筑，确认配方、工人、启停、优先级、仓储、范围和重命名可用。
7. 确认远程面板不显示五组女王动作，且修理、拆除、交付及特殊互动不能通过远程面板触发；走近后原版 `F` 仍可使用。
8. 点击空地、蓝图、Wallpaper、EnemyNexus、其他 UI、建造与命令目标，确认不会错误打开远程建筑面板。
9. 打开远程面板或设置面板时按切换键，确认必须先关闭面板才能退出模式。
10. 关闭模式，确认原先跟随女王时相机重新居中，WASD 恢复控制女王。

## 会话、存档与卸载安全

1. 模式开启时返回主菜单并切换另一存档，确认新存档默认关闭且 HUD 不重复。
2. 保存、退出并重载两轮，检查配置和原版存档都可正常读取。
3. 完全退出游戏，暂时移走 `GodViewManagement.dll`，再次启动并读取同一存档，确认原版可正常载入。
4. 检查 `BepInEx\LogOutput.log`，确认没有 Harmony 安装失败、持续异常或程序集加载错误；独立加载时也不得依赖“共享仓库”日志或 DLL。

记录测试所用游戏版本、`Assembly-CSharp.dll` SHA-256、插件 DLL SHA-256、存档备份位置和每项结果。不要把个人存档打入发布包。
