[b]English[/b]

[b]Restroom & Bathhouse Fun[/b] adds a small quality-of-life bonus to two completed hygiene services:

[list]
[*]Regular restroom: +25 Fun by default.
[*]Bathhouse: +30 Fun by default.
[*]Rewards are granted only after the service finishes normally.
[*]Electric toilets are not affected.
[*]The original 0–100 Fun cap is preserved.
[/list]

[b]Configuration[/b]

After the first launch, edit:
[code]BepInEx/config/cn.ratopia.restroombathfun.cfg[/code]

[code]
[Rewards]
ToiletFunReward = 25
BathsFunReward = 30
[/code]

Both values accept 0–100. Close the game before editing and restart it after changes. There is no in-game settings panel or live reload.

[b]Requirements[/b]

[list]
[*]Ratopia Mono build matching the inspected Assembly-CSharp.dll contract
[*]BepInEx 5 (developed against 5.4.23.5)
[/list]

[b]Installation[/b]

Close Ratopia and extract the ZIP directly into the game root. The plugin must end up at:
[code]BepInEx/plugins/RestroomBathFun/RestroomBathFun.dll[/code]

[b]Uninstallation and saves[/b]

Close the game and delete the RestroomBathFun plugin folder. The Mod adds no save fields and does not intentionally modify save data. Keep backups of important saves in any modded setup.

[b]Compatibility and verification[/b]

Mods patching the same service-completion method, replacing restroom/bathhouse service flows, or rewriting Fun may conflict. This package has passed unit, static assembly-contract, Release-build, and package-layout checks. It has not been tested in-game, so no runtime, save/reload, or uninstall acceptance claim is made. Check [code]BepInEx/LogOutput.log[/code] when troubleshooting.
