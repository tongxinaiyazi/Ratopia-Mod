# “脚手架”测试与实机验收

## 自动验证

确保 Ratopia 已完全退出，然后在项目根目录执行：

```powershell
$env:RATOPIA_DIR = 'E:\steam\steamapps\common\Ratopia'
dotnet test .\Scaffold.sln -c Release /p:InstallAfterBuild=false
.\Package.ps1 -RatopiaDir $env:RATOPIA_DIR
```

自动测试覆盖 7200 分钟边界、暂停不计时、跨日倒计时、中文格式、记录序列化、损坏记录、重复放置、移除幂等、节点覆盖与恢复、插件元数据、补丁发现，以及 Ratopia 1.0.0600 程序集哈希、字段和方法签名。

## 加载与建造入口

1. 启动游戏，检查日志中存在插件加载、数据库注册和会话初始化信息，且没有 Harmony 补丁异常。
2. 打开建造菜单，确认出现独立的“脚手架”，原版梯子仍存在且行为未改变。
3. 确认名称、说明、菜单图标和蓝图预览正确；临时移走 `Data` 后应回退原版梯子图并记录一次警告。
4. 库存中准备多个木板，连续拖动或点击放置，确认每格重新检查库存且每格只扣 `1` 个木板。
5. 确认点击后立即出现可攀爬对象，蓝图列表、搬运列表和施工列表中均无对应任务。

## 放置规则

分别验证下列位置：

- 空中、无支撑位置：允许。
- 水中：允许。
- 植物位置：允许且不移除植物。
- 普通建筑、门、路障及其他建筑占用格：允许，底层建筑不受影响。
- 实心地形、矿物、原版梯子、已有脚手架：拒绝且不扣木板。

在门和路障同格的脚手架上命令鼠民移动，确认可以攀爬通过，这是本 Mod 的预期行为。

## 寿命、寻路与拆除

1. 记录放置时刻，验证在第 `7199` 游戏分钟仍存在，第 `7200` 分钟到期。
2. 暂停游戏一段现实时间，确认剩余时间不变；复验 1 倍、2 倍和 3 倍速度。
3. 在鼠民正在攀爬时触发到期，确认脚手架安全移除，木板在原位置生成，游戏无异常。
4. 用拆除工具单点和框选脚手架，确认立即移除、返还木板且没有鼠民拆除任务。
5. 对建筑同格脚手架执行拆除，确认脚手架优先，本次操作不会给建筑添加拆除标记。
6. 在脚手架位置生成实心地块，确认脚手架立即清理并返还木板；普通建筑变化不应清理脚手架。
7. 选中脚手架，确认倒计时只随游戏分钟变化刷新；不足一小时显示“脚手架（剩余不足1小时）”。

## 存档、重载与兼容

1. 放置多个脚手架后正常保存、退出并重载，确认位置、剩余寿命和底层节点恢复正确。
2. 不退出游戏连续读取同一存档两次，确认视觉、坐标记录和返还材料均不重复。
3. 在门、路障和普通建筑同格位置分别保存、读取，再拆除脚手架，确认底层建筑节点恢复。
4. 启用 SharedWarehouse 与当前完整插件集合，重复批量放置、材料不足和拆除测试，确认无重复扣除或返还。
5. 保存后退出，临时移除 `Scaffold.dll`，确认原版能加载存档且没有隐形梯子；不要在此步骤期待木板自动返还。
6. 恢复 Mod，手动拆除脚手架并保存，再执行永久卸载验证。
7. 检查 `BepInEx\LogOutput.log`，确认没有持续异常、补丁失败、缺失依赖或资源重复计算。
