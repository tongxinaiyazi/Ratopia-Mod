# “睡觉加速”实施计划

**目标：** 测试先行实现女王入床三秒后五倍速、离床恢复及手动调速取消，并生成可直接安装的 BepInEx 5 包。

**技术栈：** C#、net472、BepInEx 5、Harmony 2、xUnit、Mono.Cecil、PowerShell。

## 任务 1：纯状态逻辑

- 先添加失败的 xUnit 测试，覆盖阈值、提前离床、暂停、恢复、手动取消、重新入床、幂等与失败重试。
- 实现 `IGameSpeedGateway` 和 `SleepAccelerationController`，只写使测试通过的最小逻辑。

## 任务 2：Ratopia 运行时适配

- 先添加程序集和插件合同测试，固定目标哈希、枚举、字段、方法、元数据和补丁入口。
- 实现插件、运行时协调器、女王帧补丁和玩家调速补丁；逐项安装并隔离异常。

## 任务 3：文档、发布与安装

- 先添加 README 和发布合同测试，再完成打包脚本与发布目录。
- 运行 Release 测试、显式无安装构建及包验证。
- 游戏关闭时备份旧 DLL、安装新 DLL并核对 SHA-256；使用测试存档完成运行时验收。
