# 睡觉加速

版本：0.1.0

“睡觉加速”是 Ratopia（鼠托邦）的独立 BepInEx 5 Mono Mod。女王在所有女王床上真正进入 `Sleep_bed` 状态后，连续经过 3 秒未暂停的真实时间，游戏会临时切换为 5 倍速。

## 行为

- 计时从女王躺稳开始，不包含走向床和上床动画。
- 游戏暂停期间不累计这 3 秒。
- 女王离开床后，恢复触发加速前玩家选择的速度。
- 5 倍速生效期间，如果玩家主动调速，新速度立即生效，本次睡眠不再自动加速，离床时也不会覆盖玩家的新选择。
- 玩家在三秒计时阶段调速不会取消计时；触发时会以最新的玩家速度作为之后的恢复值。

## 安装

要求：

- Ratopia 1.0.0600 Mono 版
- BepInEx 5.4.23.5
- Harmony 2.9.0（由 BepInEx 提供）

把压缩包内容解压到游戏根目录。DLL 的最终位置应为：

`BepInEx/plugins/SleepAcceleration/SleepAcceleration.dll`

安装或替换 DLL 前必须完全退出游戏。

## 配置、存档和卸载

本 Mod 不新增配置文件、UI、存档字段或数据库记录；等待时间固定为 3 秒，加速值固定为 5 倍速。Mod 只临时调用原版速度接口，正常使用不会改变玩家保存的速度选项。

游戏关闭后删除 `BepInEx/plugins/SleepAcceleration` 文件夹即可卸载。由于 Mod 不写入存档，移除 DLL 后原版可继续读取存档；测试时仍建议使用测试存档并保留备份，因为游戏自身可能自动保存。

## 兼容性与冲突

本版本针对以下游戏程序集构建：

- `Assembly-CSharp.dll` 文件日期：2026-07-24
- SHA-256：`C94847D858EED368D2082E9715D0C79DD79309631BEF861C6BEBD467306D6E1D`

Mod 使用 `T_Queen.Update()` Postfix 和 `SystemMgr.ApplyUserGameSpeed(float)` Postfix，不跳过原版方法。它可与当前工作区中同样给 `T_Queen.Update()` 添加轻量补丁的 Mod 并存；若其他 Mod 完全替换女王更新、强制锁定时间流速或拦截原版调速接口，仍可能发生冲突。游戏更新后应重新运行程序集合同测试。

## 日志与排错

启动和运行证据写入 `BepInEx/LogOutput.log`，包括插件发现、两个 Harmony 补丁安装、女王运行时首次调用、进入 5 倍速、恢复速度和玩家主动取消。仅出现 BepInEx 的 Loading 行不代表运行时功能已经触发。

报告问题时请附上相关 `LogOutput.log` 片段、游戏版本、启用的 Mod 列表、进入的女王床类型和复现步骤。
