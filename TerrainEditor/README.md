# 地形编辑器

将 RatopiaMod 1.5.1/1.5.2 整合源码中的 F4 地形编辑功能独立迁移到 BepInEx 5。

## 兼容环境

- 鼠托邦（Ratopia）Mono 版；本包按提供的当前游戏程序集构建。
- BepInEx 5.4.23.5。
- 不兼容 BepInEx 6 或 IL2CPP 版游戏。

## 安装

退出游戏，将压缩包内容直接解压到鼠托邦游戏根目录。最终 DLL 路径应为：

`BepInEx/plugins/TerrainEditor/TerrainEditor.dll`

## 使用

- 进入一个已经加载完成的游戏世界。
- 按 `F4` 开启或关闭地形编辑器。
- 按 `Esc` 关闭编辑器。
- 开启后使用游戏内置编辑面板选择地形、植物或地图对象。
- 面板原生支持地形绘制/替换/删除、植物放置/删除、地图对象放置/删除、画刷大小、WASD/方向键移动和滚轮缩放。

进入编辑器后镜头缩放会暂时变为 `20`，游戏速度会暂时变为 `0.3`。退出、切换场景或发生异常时，Mod 会尝试恢复进入前的镜头缩放、速度和沙盒状态。

## 重要存档提示

地形编辑会直接修改当前世界。Mod 不会自动保存，也没有撤销功能；如果之后使用游戏的保存功能，已经编辑的地形、植物和地图对象会随存档保存。建议先备份重要存档，并在测试存档中熟悉操作。

## 卸载

退出游戏后删除：

`BepInEx/plugins/TerrainEditor/TerrainEditor.dll`

已经保存进存档的世界编辑不会因为删除 DLL 自动撤销。

## 冲突与日志

- 其他监听 `F4`、修改沙盒状态或控制游戏内置 `PallateMgr` 面板的 Mod 可能发生冲突。
- BepInEx 日志：`BepInEx/LogOutput.log`。
- 插件 GUID：`cn.ratopia.terraineditor`。
- 插件版本：`0.1.0`。

## 外部游戏内验收清单

此构建只完成了离线自动测试和真实程序集合同验证，没有自动安装或启动游戏。测试人员应在备份存档中确认：

1. 加载世界后按 F4 可打开面板，再按 F4 或 Esc 可关闭。
2. 地形方块可绘制、替换和删除。
3. 植物可放置和删除。
4. 地图对象及面板中的特殊对象可放置和删除。
5. 画刷大小、WASD/方向键移动和滚轮缩放可用。
6. 关闭编辑器后镜头缩放、游戏速度和原沙盒状态恢复。
7. 开启编辑器后切换场景不会在新会话中残留编辑状态。
8. 保存并重新读取测试存档后，预期的世界编辑仍然存在。
