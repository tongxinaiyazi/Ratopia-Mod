# 游戏内验收清单

建议复制一份测试存档，不要直接使用唯一的重要存档。

## 启动

- [ ] BepInEx 日志出现 `共享仓库 v0.1.0 已加载`。
- [ ] 进入存档后日志出现共享仓库初始化统计，且没有错误或异常。
- [ ] 电力仓库仍保持原版行为。

## 容量与共享

- [ ] 普通仓库和迷你仓库显示“当前材料种类数/∞”。
- [ ] 在仓库 A 存入新材料后，仓库 B 和迷你仓库立即显示相同数量。
- [ ] 从仓库 B 取出后，仓库 A 的数量立即减少。
- [ ] 两座仓库设置不同准入、取出、数量限制和鼠民权限后，各入口仍按自己的设置工作。

## 统计与消耗

- [ ] 建造界面判断材料是否足够时，共享材料只计算一次。
- [ ] 建造实际消耗的数量与需求一致。
- [ ] 食物数量、材料数量和账本库存不随仓库数量倍增。
- [ ] 停用主仓库但保留另一座启用仓库时，活动资源统计仍正确。

## 生命周期与存档

- [ ] 新建仓库后立即接入共享库存。
- [ ] 拆除非最后一座仓库不掉落、不删除、不复制共享材料。
- [ ] 拆除当前主仓库后，其余仓库继续共享且数量不变。
- [ ] 保存、退出、读档两轮后，各材料数量均不改变。
- [ ] 用旧版无 Mod 存档载入时，各仓库材料总量按种类正确合并。
- [ ] 在启用 Mod 时保存并退出，移除 DLL 后原版仍可读档，材料只位于一座仓库。
