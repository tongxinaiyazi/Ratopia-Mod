# 共享仓库 0.1.0

让《鼠托邦》的普通仓库和迷你仓库使用同一份即时共享库存，并取消材料种类容量限制。

## 主要功能

- 普通仓库、迷你仓库：无限材料种类容量
- 所有目标仓库材料即时互通
- 每座仓库仍保留自己的筛选、数量限制和鼠民权限
- 兼容旧存档，合并时保留材料预留数据
- 防止保存、建造判断、库存/食物/账本统计重复计算
- 安全处理新建、拆除、保存和重新读档

## 要求

- 《鼠托邦》v1.0.0600
- BepInEx 5.4.23.5（Mono）

电力仓库不受影响。安装与卸载方法见压缩包中的 `README.md`。

如果游戏完整路径包含中文，请使用压缩包内的 `Launch_SharedWarehouse.cmd` 启动。它只创建临时英文盘符映射，退出游戏后自动清理。
