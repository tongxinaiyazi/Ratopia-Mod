# “广播站信号覆盖全图”Nexus Mods 发布资料设计

## 目标

为 `广播站信号覆盖全图` v0.1.1 制作一套可直接复制或上传到 Nexus Mods 的中英双语发布资料。发布内容必须忠实描述当前 Mod：电视可在全图发现并使用工作的广播站；电视服务居民的距离、广播站建筑范围、电路范围和存档范围字段均保持原版。

## 最终交付目录

建立独立交付目录，且目录中严格只有以下五个文件：

1. `1-英文标题.txt`
2. `2-简介.txt`
3. `3-双语完整介绍.txt`
4. `4-封面.png`
5. `5-广播站信号覆盖全图-v0.1.1-BepInEx5.zip`

不放入源文件、开发说明、检查清单、额外图片、散列清单或设计文档。

## 页面文案

- 英文标题使用 `Broadcast Station Global Coverage`。
- 简介提供简洁的英文与中文摘要，可直接粘贴到 Nexus Mods 简介栏。
- 完整介绍采用 Nexus BBCode，英文在前、中文在后。
- 完整介绍覆盖功能、明确不修改的内容、BepInEx 5 Mono 要求、安装、卸载、存档风险、冲突、故障排查和 v0.1.1 更新记录。
- 说明奥米伽-7“量子电网”等其他 Mod 能独立产生远距离电路效果，避免把该效果误归因于本 Mod。
- 只陈述已经验证的事实：Release 自动测试、ZIP 结构、插件加载和补丁安装已验证；远距离电视的最终游戏内行为仍列为用户验收项，不宣称已完成完整保存/卸载回归测试。

## 封面设计

- 输出格式为 PNG，横向构图，至少 1280×720。
- 采用鼠托邦氛围的原创卡通插画：地下鼠鼠城市中，一座广播站向整张地图发出清晰的信号波纹，远端电视接收到信号。
- 主视觉强调“广播信号覆盖全图”，电线只作为普通局部设施出现，不画跨地图长电线，避免错误表达。
- 封面仅使用英文标题 `Broadcast Station Global Coverage`，不使用游戏官方 Logo，不仿冒官方宣传图，不放版本号和复杂小字。
- 配色以温暖地下城棕金色、广播信号青蓝色为主，保证缩略图下仍有清晰轮廓和标题对比度。

## 安装包

- 复用并重新验证当前 v0.1.1 Release ZIP。
- ZIP 解压目标为游戏根目录。
- 插件路径必须为 `BepInEx/plugins/BroadcastStationGlobalCoverage/BroadcastStationGlobalCoverage.dll`。
- ZIP 内允许根目录 `README.md`，禁止包含游戏、Unity、BepInEx、Harmony、PDB、日志、存档、`bin` 或 `obj` 文件。

## 验证

- 视觉检查封面的标题拼写、裁切、对比度和错误电线暗示。
- 使用 Ratopia 包验证脚本检查 Mod ZIP。
- 使用 Nexus 交付验证脚本检查文件数量、命名、封面格式、版本与 ZIP 结构。
- 只有当验证输出 `RATOPIA_NEXUS_DELIVERABLES_VALID=True` 时才交付。
