# 广播站信号覆盖全图实施计划

1. 锁定目标游戏程序集哈希、枚举、字段和 Harmony 方法签名。
2. 测试先行实现广播站目标识别、候选补齐和最近工作信号源选择。
3. 实现电视手动选台与自动选台两个专用补丁，不修改共享范围字段。
4. 实现逐类补丁日志、失败回滚和卸载时撤销补丁。
5. 添加 Release 输出、依赖不复制、文档和 ZIP 结构合同测试。
6. 使用 `InstallAfterBuild=false` 构建、测试和打包，并用 Ratopia 包验证器复核。
7. 确认游戏关闭与 GUID 无重复，备份旧 DLL，安装后核对 SHA-256。
8. 启动到主界面验证 BepInEx 日志，正常关闭；游戏内远距离电视行为留作 README 人工验收。
