# 超级弓箭：全部可攻击目标战斗接入设计

## 背景与根因

实机日志证明 `Bow_Arrow.OnTriggerEnter2D` 已执行，但现有 Mod 没有进入受支持命中入口。对当前存档进行只读检查后确认，女王装备 `WoodBow`（索引 1），并且弓上精确保存了 `RangeAtk=1` 与 `BloodDrain=3`。

真实游戏程序集显示原版箭矢按目标类型分为四条伤害路径：

- `GameUnit.BeAttacked`
- `AnimalBody.BeAttacked`
- `MapObj.BeAttacked`
- `Building.BeAttacked`

岩浆水母 `Flaone` 继承 `AnimalBody`，岩浆水母巢穴 `FlaoneHole` 继承 `MapObj`。现有 Mod 只采集 `GameUnit`，因此这两类目标不会触发范围伤害或流血。

## 目标范围

采用“原版女王箭能够实际扣血”作为唯一权威条件，不再用单一 CLR 类型代表敌人。

支持以下目标：

- 原版判定为敌对且可受伤的 `GameUnit`。
- 存活并能被原版女王箭伤害的 `AnimalBody`，包括岩浆水母。
- 存活、激活且能被原版女王箭伤害的 `MapObj`，包括岩浆水母巢穴。
- 原版箭矢允许伤害的敌方建筑；当前检查版本中为 `BuildingName.EnemyNexus`。

排除友军、死亡或已销毁对象、原版箭矢不能伤害的建筑与场景物件。直接命中在 Prefix 记录生命值，在 Postfix 仅当原版调用确实使生命值下降时才进入 Mod 效果，避免复制不完整的原版判定。

## 运行时结构

新增统一的运行时目标适配层，包装 `GameUnit`、`AnimalBody`、`MapObj` 和 `Building`，向战斗逻辑提供：

- 稳定对象身份与目标种类。
- 当前位置、当前生命值和最大生命值。
- 存活、可攻击和 Boss 判定。
- 使用对应原版入口施加女王归属伤害。

`BowArrowHitPatch` 只负责采集碰撞候选、命中前生命值与箭矢伤害；原版方法返回后，根据实际生命值下降确认主目标，再调用统一战斗入口。运行时异常不会传播到游戏循环，相关效果失败时清理状态并停用对应功能。

## 范围攻击

- 仅装备精确 `WoodBow` 且具有一级 `RangeAtk=1` 时触发。
- 以已确认的主目标为圆心，半径 1.5 格。
- 枚举 `List_AllEnemy`、`AnimalMgr.List_Animal`、`MapObjMgr.List_MapObj` 和 `BuildingMgr.List_Building`。
- 使用与原版女王箭一致的可攻击规则，排除主目标、友军、死亡目标、不可攻击建筑和重复对象。
- 每个次要目标受到箭矢直击伤害的 50%。
- 范围伤害经目标对应的原版受伤入口结算，不递归触发下一轮范围伤害。

## 流血

- 仅装备精确 `WoodBow` 且具有二级 `BloodDrain=3` 时触发。
- 直击目标和本次范围伤害命中的全部支持目标都可进入同一个流血状态机。
- 首次命中后的第 1、2、3 秒各结算一跳。
- 只有 `GameEnemy` 且 `EnemyCategory.Boss` 的目标每跳损失最大生命值 1%。
- 其他全部支持目标，包括动物、巢穴和敌方建筑，每跳损失最大生命值 3%。
- 重复命中只刷新到期时间，不叠层，也不推迟已经排定的下一跳。
- 目标死亡、销毁、切换场景、返回标题或插件关闭时清理状态。

## 数据、提示与兼容性

- 重铸候选的 WoodBow 专属上下文修复保持不变。
- 游戏内 `BloodDrain=3` 提示保持为“流血”。
- 不改变存档结构，不迁移或重写现有词条。
- 保持与“装备重铸自选属性”Mod 的现有 Harmony 优先级兼容策略。
- 版本提升为 `0.1.2`，日志分别记录 `GameUnit`、`AnimalBody`、`MapObj` 与敌方建筑的首次有效命中。

## 测试与验收

- 先写失败测试，证明现有仅 `GameUnit` 状态无法表达岩浆水母与巢穴。
- 纯逻辑测试覆盖四类目标身份、命中前后生命值确认、主目标排除、去重、半径边界、50% 范围伤害和 Boss/普通流血倍率。
- 流血时间线对四类目标运行同一套刷新、不叠层与三跳规则。
- 静态合同锁定四条原版受伤方法、管理器列表、生命字段和 `EnemyNexus` 判定所需字段。
- Release 测试、构建、包结构检查通过后，确认 Ratopia 已退出，备份并安装 DLL。
- 实机验收必须分别命中普通敌对 `GameUnit`、岩浆水母、岩浆水母巢穴和 Boss；日志要证明原版扣血确认、范围命中与流血跳伤均发生。
