# 超级弓箭战斗效果修复设计

## 问题证据

- `Player.log` 证明插件、数据库补丁和重铸 UI 均已执行，但没有出现女王弓箭命中入口日志。
- 同一日志记录本次重铸对象为物品索引 `0`；当前游戏资产中索引 `0` 是 `Gradius`，`WoodBow` 是索引 `1`。
- `ItemEnhanceInfo.Type == 1` 是武器共享重铸池，不是 WoodBow 专属池。把特殊候选永久追加到该列表，会让其他武器显示并保存只为 WoodBow 实现的词条。

## 修复范围

- “范围攻击”和“流血”严格限定 `WoodBow`（索引 `1`、类型 `1`、名称 `WoodBow`）。
- 打开 WoodBow 重铸详情或实际重铸 WoodBow 前，临时把两个特殊候选加入共享池。
- 打开任何非 WoodBow 装备、切换场景或卸载插件时，只移除本插件拥有的临时候选；不删除其他 Mod 的同值条目。
- WoodBow 基础 ATK 修改继续在数据库会话期间保持，并按原有所有权规则恢复。
- 箭矢碰撞入口先记录一次补丁调用，再执行 WoodBow、敌对单位与词条检查，以便区分“补丁没执行”和“装备条件不匹配”。
- 流血提示文本严格为 `流血`，不包含数值说明。
- 范围半径、50%伤害、流血三跳、普通敌人 3%、Boss 1% 与刷新规则均不改变。

## 兼容与失败处理

- 继续使用原版 `RangeAtk=1` 与 `BloodDrain=3` 保存组合，不改变存档结构。
- 兼容原版重铸以及已安装的“装备重铸自选属性”：上下文补丁在 `BuildMidUI.ItemDetail_Open` 前设置候选，重铸操作补丁在 `T_Queen.ItemEnhance` 前再次校准。
- 任一上下文候选操作异常时回滚本插件拥有的候选，并记录错误；异常不传播到游戏循环。
- 版本提升为 `0.1.1`，便于从日志确认已加载修复版。

## 验收

- 非 WoodBow 上下文不暴露本插件拥有的两个特殊候选。
- WoodBow 上下文只追加一次，列表和值保持对齐，切换到非 WoodBow 后恢复。
- 正确装备带词条的 WoodBow 后，日志出现碰撞入口和受支持命中入口。
- 提示只显示“流血”。
- Release 测试、构建、包审计和安装哈希全部通过。
