# 装备重铸自选属性

`装备重铸自选属性` 是 Ratopia（鼠托邦）的 BepInEx 5 插件。它在皇家铁匠铺（Royal，1 级）和地狱铁砧（HellAnvil，2 级）的装备重铸界面中列出当前装备可用的原版属性，玩家可选择这次重铸的属性。

## 版本与运行环境

- Mod 版本：`0.1.2`
- 插件 GUID：`cn.ratopia.equipmentreforgeselector`
- 运行时：BepInEx 5（Mono），`.NET Framework 4.7.2`
- 已检查的游戏构建：`Assembly-CSharp.dll`，本地构建文件日期 `2026-07-24`，SHA-256 `C94847D858EED368D2082E9715D0C79DD79309631BEF861C6BEBD467306D6E1D`

此插件只面向上述已检查的游戏程序集构建。游戏更新后，请先确认 Mod 的兼容性再继续使用。

## 安装

1. 完全退出 Ratopia。
2. 解压发布包到 Ratopia 游戏根目录，保持目录结构不变。
3. 确认文件位于 `BepInEx\plugins\EquipmentReforgeSelector\EquipmentReforgeSelector.dll`。
4. 启动游戏；不要同时放置同 GUID 的旧版或重复 DLL。

发布包不包含游戏、Unity、BepInEx 或 Harmony 的 DLL。请自行安装与游戏匹配的 BepInEx 5。

## 使用方法

1. 在皇家铁匠铺（Royal，1 级）或地狱铁砧（HellAnvil，2 级）打开支持的装备详情。
2. 直接点击原版米色“效果列表”中的候选整行；属性文字、图标和同一行空白区域都属于点击范围。当前选择会显示原版绿色箭头、浅绿色背景和“已选择”。
3. 每行左侧带有 `[1]`、`[2]` 等编号，可以按主键盘或小键盘数字键直接选择；候选项获得焦点后，也可以用上下键移动并以回车确认。
4. 执行原版重铸操作；材料、价值、提示、成就与保存格式继续由原版逻辑处理。

支持武器、衣服与饰品，只显示与当前装备类别和重铸等级相符的原版候选项；当前等级已拥有的同一属性不会再次显示。

`0.1.2` 不再创建额外的右侧深色面板。选择交互只绑定到原版 `重铸效果` 列表，其他米色提示框继续使用原版行为。

鼠标划过中间“效果”和“重铸效果”的四个格子时，原版会临时刷新右侧米色提示内容；此刷新只暂停可见按钮，不会清除已经选择的属性。再次显示相同装备、相同阶级的重铸效果列表时，原选择和标记会自动恢复。更换装备、切换重铸阶级、关闭详情、切换场景或完成重铸后，旧选择会被重置或重新验证。

## 原版随机回退与兼容性

选择无效、候选资料异常、没有可选项目，或 UI 未能建立时，插件会记录警告并让本次操作使用**原版随机**流程。此回退仍由原版扣除资源与处理结果。

插件不替换原版存档架构，也不打包第三方依赖。与修改同一重铸流程、属性候选表或 `T_Queen.ItemEnhance` 的 Mod 可能冲突；请一次只启用一个同类 Mod 进行排查。

## 存档风险、备份与卸载

使用前请备份重要存档。尽管插件只在执行重铸时临时缩小原版候选列表并在结束后恢复，仍应在新建存档和测试存档上完成 `docs/TESTING.md` 的读档验证。

卸载步骤：退出游戏，删除 `BepInEx\plugins\EquipmentReforgeSelector\EquipmentReforgeSelector.dll`（或整个同名插件目录），再用备份和测试存档确认原版可读。请不要在游戏运行时覆盖或删除 DLL。

## 日志位置

启动、补丁安装、回退和异常信息写入 `BepInEx\LogOutput.log`。发生问题时，请附上该日志中从“发现插件”开始的相关片段，并说明游戏版本、已启用 Mod 与复现步骤。
